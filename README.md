# anna1995d.github.io

Personal website for **Anahita Doosti Sanjani** — Machine Learning Educator and Researcher based in Edmonton, AB.

## About

A multi-page personal portfolio built with plain HTML and CSS — no frameworks, no dependencies. The site presents Anahita's professional background, research projects, and academic history in a sharp, modern dark-themed design.

## Live Site

Hosted with [GitHub Pages](https://pages.github.com/):

**[https://anna1995d.github.io](https://anna1995d.github.io)**

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Introduction, bio, skills overview, and contact links |
| Experience | `experience.html` | Full professional and teaching history |
| Projects | `projects.html` | Technical projects and published research |
